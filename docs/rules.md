# Challenge rules — draft

The official rules are not yet finalized. The submission deadline is April 25, 2027; cutoff time and timezone remain to be announced. Do not treat proposed evaluation code as the adopted competition protocol.

## To finalize before opening submissions

- Eligible participants, teams and organizer participation.
- Permitted training splits, external data, pretrained models and model/API services.
- Task tracks and available input modalities.
- Submission format, limits and final submission selection.
- Primary metric, aggregation and tie handling.
- Required code, model and method-report verification for final rankings.
- Dataset access conditions and redistribution restrictions.
- Handling of invalid submissions, protocol corrections and appeals.
- Sponsor and prize terms, if applicable.

Evaluation-specific decisions are listed in [the task specification](task.md).
