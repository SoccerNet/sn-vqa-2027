# Baselines

The [test predictions](../data/test_submission.json) and [challenge predictions](../data/challenge_submission.json) were supplied by the [task lead's reference repository](https://github.com/jyrao/soccernet-streaming-vqa-challenge), which describes them as GPT-5.5 baseline submissions. The challenge scores are not published here because their reference labels are private. Test them locally with the [evaluator](../evaluation/README.md).

The source also includes a [text-only API baseline script](https://github.com/jyrao/soccernet-streaming-vqa-challenge/blob/6e71e319e1f0c74bd5d5a096d986b4c3dbb9388c/baseline/baseline_osl.py) and links to [MatchLive](https://github.com/Becomebright/MatchLive), a streaming video method. These are starting points, not yet frozen 2027 reference runs. The text-only baseline does not inspect video; participants should read the [task rules](../RULES.md) before adapting it. Record model/API versions, prompts, permitted inputs, compute, and a reproducible run when final baselines are selected.

Open [SN-VQA-2027](https://huggingface.co/datasets/SoccerNet/SN-VQA-2027) and download the dataset with `hf download SoccerNet/SN-VQA-2027 --repo-type dataset --local-dir ./SN-VQA-2027`. From **this repository's root**, run `python evaluation/eval_predictions.py data/test_submission.json data/test_GT.json` to reproduce the supplied test-file score. This scores an included file; it does not regenerate it. To regenerate predictions, clone the [task lead's source repository](https://github.com/jyrao/soccernet-streaming-vqa-challenge), follow its environment/API setup, and run `python baseline/baseline_osl.py --input /path/to/challenge_public.json --output /path/to/predictions.json` from that repository root with a configured API key. The exact model/API version, prompt, settings, and producing commit of the supplied prediction files still need confirmation. MatchLive requires a separate input adapter.
